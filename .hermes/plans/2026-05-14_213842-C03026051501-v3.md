# 计划：多零件号生产单工艺自动化流程改造（V3 — ERP决定模式版）

## 目标

通用处理 N 个零件的生产单，不依赖文件名约定判断单/多零件。

## 核心设计原则

**文件名约定：** `{prod_no}-{part_no}.pdf`，用第一个 `-` 切分
- `W20126051401.pdf` → prod_no=W20126051401, part_no=None
- `W20126051401-001.pdf` → prod_no=W20126051401, part_no=001
- `C03026051501-001.pdf` → prod_no=C03026051501, part_no=001
- `C03026051501-A1.pdf` → prod_no=C03026051501, part_no=A1

**但生产单是单零件还是多零件，由 ERP 表行数决定，不靠文件名猜。**

## 完整流程

```
输入: --drawings-dir /Volumes/m2/erp/  [--prod-no 可选过滤] [--parts 可选过滤]

Step 0: 扫文件夹
  → 按文件名分组: { prod_no: [(part_no, path), ...] }
  → 去掉不匹配 --prod-no / --parts 的
  → 按 prod_no 分组输出

Step 1: 视觉+推理（提前做，批量，不依赖浏览器）
  for each (prod_no, [(part_no, pdf_path), ...]):
      for each (part_no, pdf_path):
          vision_result = vision.analyze(pdf_path)
          process_plan = reason_process(vision_result)
          缓存 plans[(prod_no, part_no_or_None)]

Step 2: 启动浏览器，登录ERP，导航到计划工艺

Step 3: 按 prod_no 逐一处理
  for each prod_no:
      ERP搜索该 prod_no
      统计行数 N

      if N == 1:
          ── 单零件模式 ──
          plan = 从缓存取 plans[(prod_no, None)]
                  或 plans[(prod_no, 任意part_no)]  // 单文件带后缀也取得到
          勾选该行 → 开弹窗 → 填 → 保存
          log("单零件完成")

      if N >= 2:
          ── 多零件模式 ──
          for each 行 in ERP表（有 生产单号 + 零件号 两列）:
              part_no = 该行的零件号列的值
              if (prod_no, part_no) 在缓存中有:
                  plan = 缓存中的plan
                  勾选该行 → 开弹窗 → 填 → 保存 → 关弹窗
              else:
                  log(f"零件 {part_no} 在图纸中找不到，跳过")
```

## 文件扫描逻辑

```python
def scan_drawings(drawings_dir: str) -> dict:
    """返回 { prod_no: [(part_no, path), ...] }"""
    result = defaultdict(list)
    for f in sorted(Path(drawings_dir).glob("*.pdf")):
        stem = f.stem
        if "-" in stem:
            idx = stem.index("-")
            prod_no = stem[:idx]
            part_no = stem[idx+1:]
        else:
            prod_no = stem
            part_no = None
        result[prod_no].append((part_no, str(f)))
    return dict(result)
```

## 行匹配逻辑

```javascript
// 单零件：匹配生产单号即可
function findSinglePartRow(prodNo) {
    for (let row of document.querySelectorAll('.vxe-body--row')) {
        let text = row.textContent;
        if (text.includes(prodNo)) return row;
    }
    return null;
}

// 多零件：同时匹配生产单号 + 零件号（零件号列索引动态查）
function findMultiPartRow(prodNo, partNo) {
    // 先找"零件号"列索引
    let headers = document.querySelectorAll('.vxe-header--row .vxe-cell--title');
    let partCol = -1;
    Array.from(headers).forEach((h, i) => {
        if (h.textContent.trim() === '零件号') partCol = i;
    });
    if (partCol === -1) return null;  // 找不到列

    for (let row of document.querySelectorAll('.vxe-body--row')) {
        let cells = row.querySelectorAll('td .vxe-cell');
        let partCell = cells[partCol]?.textContent.trim();
        let prodCell = cells[2]?.textContent.trim();  // 索引2已知是生产单号
        if (prodCell === prodNo && partCell === partNo) return row;
    }
    return null;
}
```

## 边界情况处理

| 情况 | 行为 |
|------|------|
| 文件夹内无 PDF | 报错 |
| 生产单在ERP中搜不到 | 警告+跳过该单号 |
| ERP中2行但只有1张图纸 | 能处理的零件处理，另一个零件跳过+提示 |
| 文件名 `X-001.pdf` 但ERP该单号只有1行 | 单零件模式直接填，不匹配零件号 |
| 文件无后缀 `X.pdf` 但ERP该单号有2行 | 警告：多零件但只有1张图纸，只填匹配上的行（按零件号None匹配不到，跳过） |
| 多零件处理中某零件保存失败 | 继续下一个零件，出错零件日志记录 |
| 从文件名切分出的零件号是"001"但ERP中写的是"1" | 字符串精确匹配，不匹配则跳过+记录 |
