# 计划：多零件号生产单工艺自动化流程改造（V2 — 通用版）

## 目标

使 `fill_by_vision.py` 能处理 **N 个零件**（0..N）的生产单：

- **单零件**（1张图纸）：保持现有逻辑不变，按 `prod_no` 匹配行
- **多零件**（N 张图纸）：每个零件独立分析图纸 → 在 ERP 中按 `prod_no + 零件号` 精确匹配行 → 独立填工艺 → 保存 → 下一轮

## 两种模式

### 模式 A — 单零件（向后兼容）

```
python scripts/fill_by_vision.py --drawing /path/to/pdf --prod-no W20126051401 --account 472
```

→ 行为与当前代码完全一致，只是账号可指定

### 模式 B — 多零件

```
python scripts/fill_by_vision.py --drawings-dir /Volumes/m2/erp/ --prod-no C03026051501 --account 472
```

→ 自动扫描目录下 `{prod_no}-*.pdf`，提取零件号，按 N 个循环处理

也可指定零件号子集：

```
python scripts/fill_by_vision.py \
    --drawings-dir /Volumes/m2/erp/ \
    --prod-no C03026051501 \
    --parts 001,003
```

## 图纸发现逻辑

```
def scan_drawings(drawings_dir: str, prod_no: str, parts: list[str] | None) -> list[(part_no, pdf_path)]:
    files = list(drawings_dir.glob(f"{prod_no}-*.pdf"))
    # 从文件名提取零件号: C03026051501-001.pdf → "001"
    discovered = []
    for f in sorted(files):
        match = re.match(rf"{re.escape(prod_no)}-(.+)\.pdf$", f.name)
        if match:
            discovered.append((match.group(1), str(f)))
    
    if parts is not None:
        discovered = [(p, path) for p, path in discovered if p in parts]
    
    # 无图纸 → 报错
    # 1张 → 单零件模式
    # N张 → 多零件模式
    return discovered
```

## N 零件循环核心流程

```python
parts_drawings = scan_drawings(drawings_dir, prod_no, parts_filter)

# 提前完成所有推理（不依赖浏览器）
plans = {}
for part_no, pdf_path in parts_drawings:
    vision_result = vision.analyze(drawing_path=pdf_path, prod_no=f"{prod_no}-{part_no}")
    full_plan = reason_process(vision_result.part_info, vision_result.features, ...)
    plans[part_no] = map_to_erp_processes(full_plan)

# 浏览器只启动一次
browser = start_browser()
navigate_to_工艺页面()
search_and_find_tab(prod_no)

# 循环处理每个零件
for part_no, plan in plans.items():
    log.info(f"===== 处理零件 {part_no} =====")
    
    # 定位行：同时匹配 prod_no AND 零件号
    row = find_row_by_prod_and_part(page, prod_no, part_no)  # ← 关键改动
    
    if row is None:
        log.warning(f"零件 {part_no} 在ERP表中找不到对应行，跳过")
        continue
    
    # 勾选该行 → 点工艺管理
    click_checkbox(row)
    click_工艺管理按钮()
    wait_for_dialog()
    
    # 填工序 → 保存
    fill_processes(page, plan)
    save_and_confirm(page)
    
    # 取消勾选 → 等待弹窗完全关闭
    uncheck_row(page, row)
    wait_for_dialog_close()

# 完成后总结
log_summary(plans)
```

## 行定位函数（核心改动）

```javascript
function findRowByProdAndPart(prodNo, partNo) {
    const rows = document.querySelectorAll('.vxe-body--row');
    for (let row of rows) {
        const cells = row.querySelectorAll('td .vxe-cell');
        // 根据表头：索引2=生产单号, 索引3=零件号
        const prodCell = cells[2]?.textContent.trim();
        const partCell = cells[3]?.textContent.trim();
        if (prodCell === prodNo && partCell === partNo) {
            return row;
        }
    }
    return null;
}
```

## 风险

| 风险 | 缓解措施 |
|------|----------|
| 多零件弹窗交替打开有竞态 | 每轮严格串行：选行→开窗→填→保存→关窗→取消选中→等半秒→下一个 |
| 零件号列索引在不同标签页不同 | 根据表头头动态定位索引：`headers.indexOf("零件号")` |
| STAVAX ESR圆形零件推理结果异常 | 先跑1个零件看效果，确认推理结果正确再批量跑 |
| 账号472的持久化session不存在 | `fill_by_vision.py` 同步更新 `ERP_USERNAME` 环境变量读取 |
