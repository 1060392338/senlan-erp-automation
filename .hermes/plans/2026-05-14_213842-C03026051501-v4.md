# 计划：多零件号生产单工艺自动化流程改造（V4 — 图纸完整性校验版）

## 核心原则

1. **ERP是零件清单的权威来源** — 搜出几行就有几个零件
2. **图纸目录必须涵盖所有零件** — 缺一张就不跑，报错提示
3. **文件名约定** `{prod_no}-{part_no}.pdf`（包括单零件文件也可能带后缀）

## 完整流程

```
输入: --drawings-dir /Volumes/m2/erp/ [--prod-no 可选] [--parts 可选] [--drawing 向后兼容]

Step 0: 扫描图纸目录
  → 按文件名分组: { prod_no: {part_no: pdf_path, ...} }
  → 过滤 --prod-no 和 --parts

Step 1: 批量视觉分析 + 推理（不依赖浏览器，提前做完）
  for each (prod_no, {part_no: path, ...}):
      for each (part_no, pdf_path):
          vision → reason_process → 缓存 plan

Step 2: 启动浏览器，登录ERP，导航到计划工艺

Step 3: 按 prod_no 逐一处理
  for each prod_no from Step 0:

      搜索ERP表 → 获取该单号的所有行
      erp_parts = [每行的零件号字段值]

      ── 图纸完整性校验 ──
      missing = [p for p in erp_parts if p not in 图纸缓存]
      if missing:
          ❌ FATAL: 以下零件在ERP中存在但缺少图纸：
              零件号 M1（规格Φxx, 零件名称xxx）→ 缺 {prod_no}-M1.pdf
              零件号 M2（规格Φyy, 零件名称yyy）→ 缺 {prod_no}-M2.pdf
          ❌ 终止处理该生产单，跳到下一个prod_no（或全部终止）

      ✅ 全部匹配 → 按零件号逐一填工序
      for each 行 in ERP表:
          part_no = 该行的零件号
          勾选该行 → 开弹窗 → 填plan → 保存 → 关弹窗

Step 4: 打印完成报告
```

## 图纸扫描

```python
def scan_drawings(drawings_dir: str) -> dict:
    """返回 { prod_no: {part_no: pdf_path} }
    文件名规则: {prod_no}-{part_no}.pdf
    无后缀的文件: prod_no=None (单零件兼容)
    """
    result = defaultdict(dict)
    for f in sorted(Path(drawings_dir).glob("*.pdf")):
        stem = f.stem
        if "-" in stem:
            idx = stem.index("-")
            prod_no = stem[:idx]
            part_no = stem[idx+1:]
        else:
            prod_no = stem
            part_no = None
        result[prod_no][part_no] = str(f)
    return dict(result)
```

## 单/多零件判定（ERP驱动）

不是死区分的，而是：

| ERP搜出行数 | 模式 | 行为 |
|-------------|------|------|
| 0 | 错误 | 该prod_no在系统不存在 |
| 1 | 单零件 | 不依赖零件号匹配，直接填（兼容文件名带/不带后缀） |
| ≥2 | 多零件 | 逐行检查零件号 → 匹配对应图纸 → 缺图报错 → 全部匹配才处理 |

## 错误处理

| 情况 | 行为 |
|------|------|
| 某生产单缺零件图纸 | ❌ 终止该单，列出缺图清单，不清除已完成的单 |
| ERP搜不到该生产单 | 警告+跳过 |
| 保存失败 | 重试1次，仍失败则记录错误继续下一个零件 |
| 文件名无后缀但ERP多行 | 警告+跳过（无法匹配零件号） |
