# 计划：多零件号生产单工艺自动化流程改造

## 目标

生产单 `C03026051501` 对应 2 个零件号（001、002），各有独立图纸。改造现有 `fill_by_vision.py`，使其能：
1. 识别同一生产单下的多个零件号
2. 分别分析对应图纸 → 推理工艺 → 在 ERP 中定位到正确的行（按零件号区分）→ 填入 → 保存

## 现状

| 项目 | 当前 |
|------|------|
| 模具号(`mold_no`) | : `C03026051501` |
| 零件数 | 2 个（001 + 002） |
| 零件001 | 前模镶件 / Φ10×107.3 / 500件 / STAVAX ESR |
| 零件002 | 后模镶件 / Φ14×30.7 / 800件 / STAVAX ESR |
| 标签位置 | **未发送**（非BOM清单） |
| 图纸 | `/Volumes/m2/erp/C03026051501-001.pdf` / `-002.pdf` |
| 形状 | 圆件（圆形零件） |
| 账号 | 472（当前代码写死 473） |

## 变更计划

### Step 1：CLI 入口改造

**文件：** `scripts/fill_by_vision.py`

- 新增 `--part-no` 参数，对应零件号
- 新增 `--drawings-dir` 参数，指定图纸目录（自动按 `{prod_no}-{part_no}.pdf` 匹配）
- 去除 `PROD_NO_DEFAULT` 默认值（强制用户指定）

```bash
python scripts/fill_by_vision.py \
    --prod-no C03026051501 \
    --part-no 001,002 \
    --drawings-dir /Volumes/m2/erp/ \
    --account 472
```

### Step 2：账号改为 472

**文件：** `scripts/fill_by_vision.py` + `services/playwright_erp.py`

- 默认账号从 `473` 改为 `472`
- 新增 `--account` CLI 参数 + 环境变量 `ERP_USERNAME`
- 或者统一用 `--account` 参数传入，不再硬编码

### Step 3：行定位增加零件号匹配

**文件：** `scripts/fill_by_vision.py`（`run()` 函数中搜索和勾选部分）

当前第 4~5 步（搜索+勾选）只匹配 `prod_no`，需改为**同时匹配 `prod_no` 和 `part_no`**：

```javascript
// 搜索时：检查行内容同时包含生产单号和零件号
for(let r of document.querySelectorAll('.vxe-body--row'))
    if((r.textContent||'').includes('{prod_no}') && 
       r.querySelectorAll('td')[3]?.textContent.trim() === '{part_no}')
        return true;
```

### Step 5：标签页从 BOM清单 改为 未发送

当前代码遍历 `["BOM清单", "未发送", "已发送"]`，但对于 `C03026051501`，数据在**未发送**标签。保持遍历逻辑不变，但优先搜索**未发送**。

### Step 6：弹窗关闭时机

每次填写一个零件后保存 → 弹窗关闭 → 取消勾选当前行 → 再选中下一行 → 重新打开弹窗。

### Step 7：零件号传给推理引擎

当前 `VisionAgent.analyze()` 只接收 `prod_no`，需同时传递 `part_no` 以便日志和错误信息能定位到具体零件。

## 风险

| 风险 | 缓解 |
|------|------|
| 弹窗保存后影响下一行 | 每轮填完立即保存+关闭弹窗，然后取消当前行勾选 |
| 搜索不到行的零件号列索引偏移 | 通过表头动态定位零件号列索引（headers.indexOf("零件号")） |
| 两个零件工序差异大 | 各自独立推理，互不影响 |
| 账号472可能需要新登录 | 使用 `--account 472` + persistent_context 保持登录态 |

## 注意事项

- **红线**：只操作 `C03026051501` 的单子，不改其他单
- **零件号规则**：001 对应图纸 `-001.pdf`，002 对应 `-002.pdf`
- **保存后必须确认**：检查 toast 或弹窗关闭，然后才处理下一个零件
